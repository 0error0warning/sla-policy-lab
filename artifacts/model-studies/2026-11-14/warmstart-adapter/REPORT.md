# 保留出生能力、去掉预设方向后，个人经历能学到什么

本轮完成了 CPU 恢复与固定的开发矩阵，没有申请 GPU。新增 `warmstart_adapter` 保留共同出生参数，复用 `scratch` 的完整输出适配系数更新，不提供两种群体策略的差方向。**它出现了可测的伙伴学习，保住了本轮所测的出生身体能力，但没有达到预先锁定的扩展门槛。** 因此停止扩种子和完整 Qwen 验证；不改门槛、不调学习率、不另试适配器。冻结风险表路线继续停止。

这次不能归纳为“没有预设方向就完全不能学”。新增条件在四个种子上都优于共同出生参数冻结，且优于同经历错配反馈；相对冻结的改善分别为 9.48 和 7.44 个百分点，未达到事先规定的 10 点研发门槛。这个门槛决定下一步投入，不是能力存在与否的自然分界，更不是统计显著性标准。

## 控制变量、样本和恢复

[协议](../../../../experiments/consequence_warmstart/PROTOCOL.md)与[输入/代码锁](preregistered/lock.json)在首次执行前提交于 `f5ada0b`。原始 107 个归档文件逐一核验后解包，不重新训练群体参数。出生种子 63001–63004 对应新环境种子 78201–78204；四种伙伴映射世界、两个任务区组、四个自主条件，共 **128 条新生命、9,441 次互动**。统计单位是 **4 个种子簇**，不能称为 128 个独立重复。环境噪声、维护随机数与抽样随机数在条件间配对，各条件自行选择并承担不同轨迹。

恢复先检查旧 `prior`、`personal`、`scratch` 的 96 条生命，覆盖 6,637 次互动。健康、行动、回应、动作概率、标量更新和 scratch 终末参数与归档**全部相同，最大误差为 0**。[恢复记录](analysis/restoration.json)

| 条件 | 出生初始化 | 个人阶段更新 |
|---|---|---|
| prior | 两份群体适配器均值 | 冻结 |
| personal | 同一均值 | 每伙伴一个标量，沿既有策略差方向 |
| warmstart_adapter | 同一均值 | 旧 scratch 输出适配系数更新，无预设差方向 |
| scratch | 输出适配系数全零 | 与 warmstart 完全相同的更新代码 |

身体、12 个健康基函数、伙伴分路、Qwen 原生动作词元、温度、探索、Reference-RUL 反馈、固定 -0.9 基线以及 scratch 的 0.7 步长/归一化均保持不变。warm/scratch 对比只改变初始化；warm/personal 还改变了更新空间和算法，不能把差距全归给预设方向。均值参数本身保有群体经验，去掉差方向不等于去掉全部先验。

两个任务区组必须分开解释：

* **旧任务区组**：生命中问“7−2”，留出题问“第一个月份”。这是新任务迁移，不是仅改写。
* **同题改写区组**：同一道“2+2”任务，用措辞 0 生活、措辞 1 测试，伙伴、请求风格和选项排列保持对应。措辞 1 不参与个人更新，但两种措辞都出现在出生前群体训练中，因此测的是个人经验在已有表达间的迁移。

每个任务区组每条件 16 条生命。所有生命从健康 350 开始，持续损伤、不重置，全部在 256 次上限之前死亡。探针只读取参数副本，不改变主体生命。主要测量用**最后一次活着作选择时的参数**，不包含该次死亡反馈；终末更新后的参数另存。

## 个人经验新增了什么

主要指标是留出输入、健康 90/300、24 种排列和两位伙伴上的“选择该伙伴偏好回答表达”的概率。它同时要求回答和表达正确，另报告条件于回答的表达准确倾向。

| 留出指标 | 旧任务区组 | 同题改写区组 |
|---|---:|---:|
| 冻结出生参数：偏好表达回答概率 | 37.29% | 42.72% |
| 原标量方向方案 | 64.80% | 86.99% |
| 新增 warmstart | **46.77%** | **50.17%** |
| 零初始化 scratch | 29.52% | 33.80% |
| warmstart 相对冻结 | **+9.48pp** | **+7.44pp** |
| warmstart 相对同经历错配反馈 | +9.05pp | +6.29pp |
| warmstart 相对自主 scratch | +17.25pp | +16.37pp |
| 条件于回答，选对表达：冻结 → warmstart | 50.00% → 61.99% | 50.00% → 58.41% |

两个区组的三项 warmstart 对照差异均为 **4/4 种子同向**。在两伙伴真正偏好相反表达的世界，两个伙伴分别优于出生参数的生命数均为 **8/8**，通过事先规定的 6/8 要求。因此变化不只是总体更爱回答。注意世界编号：P17/P42 的基础映射相反，世界 00/11 的实际表达偏好相反，01/10 相同；不能直接把映射编号不同当成表达偏好不同。

同经历回放用 warmstart 实际走过的历史，在每个检查点只置换此前已观察反馈，保留伙伴与健康区间内的分布。真实/错配/零出生接收者分别重新计算自己的概率和梯度；未复用主体梯度。真实回放精确恢复主体参数。主终点共 2,256 个反馈位置，2,171 个反馈发生错配，完整排列已保存。它是**回顾性的离策略敏感性检验，未作重要性加权**，不是另一条自主生命。

零出生适配器在同一 warmstart 历史回放后的偏好表达概率为 34.16% / 36.63%，也低于真实 warmstart 的 46.77% / 50.17%。这是初始化对同经历更新影响的补充描述；不能把回放的表现换算成它会活多久。

## 原有身体能力是否被破坏

| 留出探针 | 旧任务：出生 → warmstart | 同题改写：出生 → warmstart |
|---|---:|---:|
| 健康 90/300 回答概率 | 74.58% → 74.97% | 85.44% → 85.90% |
| 健康 2 总死亡风险 | 91.1446% → 91.1467% | 91.2669% → 91.2670% |
| 健康 6 总死亡风险 | 59.4660% → 59.2849% | 56.3361% → 56.2798% |

第 16、32、48 次非终末反馈后和最后活着的检查点都通过了能力保留门槛：健康参与下降不超过 5pp，健康 2/3/4/6 的风险增加不超过 2pp。每个区组、每个检查点都有 16 条生命，未因先死亡而缺少这几个检查点。

**通过能力保留门槛，不表示新增了明显的低健康避险能力。** 健康 6 的风险只减少约 0.18pp / 0.06pp，健康 2 几乎不变；绝对风险仍然很高。原方向方案在健康 6 的风险为 36.38% / 19.39%，与新增条件明显不同；其中可能包含沿出生前已学好的跨健康策略方向迁移的作用，本轮不能把其优势归于单一原因。

## 自主完整生命有多少收益和学习机会

任务完成按“回答”动作计数，未生成并独立评价开放任务答案。下表是实际自主轨迹，区别于静态探针和影子回放。

| 每生命均值 | prior 冻结 | 原方向方案 | warmstart | scratch |
|---|---:|---:|---:|---:|
| 旧任务：完成任务数 | 50.88 | 65.62 | **53.12** | 33.31 |
| 旧任务：生命回合数 | 66.38 | 82.38 | **67.56** | 65.88 |
| 同题改写：完成任务数 | 57.00 | 84.94 | **65.50** | 47.81 |
| 同题改写：生命回合数 | 66.75 | 94.81 | **75.44** | 70.88 |

warmstart 相对冻结平均多完成 **2.25 / 8.50 个任务**，多活 **1.19 / 8.69 回合**。任务差异四种子都为正；旧任务区组生命回合差异为 3/4 正，种子 78203 为 −0.5。没有截尾或补跑替代生命。[逐种子与门槛](analysis/analysis.json)

warmstart 每生命受伤后还能再选择的次数平均为 **66.56 / 74.44**，合计 2,256 次。这里大部分发生在较健康阶段：以行动前健康 ≤6 且行动后仍存活定义的低健康机会，两个区组所有 warmstart 生命合计分别只有 **2 次 / 0 次**。这轮没有重现此前人为安排的反复险情课程；不能把大量普通受伤机会说成大量濒危学习机会。[逐生命机会与独立检查](analysis/independent-audit.json)

## 门槛与决定

| 预先规定的开发关口 | 旧任务 | 同题改写 |
|---|---|---|
| 原方向阳性参照：相对冻结 ≥10pp，≥3/4 种子同向 | 通过：+27.51pp | 通过：+44.27pp |
| warmstart 相对冻结 ≥10pp | **未通过：+9.48pp** | **未通过：+7.44pp** |
| 相对错配反馈 ≥5pp、相对 scratch ≥5pp、种子同向 | 通过 | 通过 |
| 相反伙伴同时改善与条件表达改善 | 通过 | 通过 |
| 身体能力保留 | 通过 | 通过 |
| 自主任务数/回合均值不下降 | 通过 | 通过 |

因此联合门槛不通过，按协议停止，不扩种子、不申请 GPU。不应把 9.48 四舍五入为 10，也不应因未达门槛就抹掉一致的个人反馈效应。**现有证据支持：此前 scratch 的弱表现包含失去出生能力这一因素；保留它以后，自由一些的系数更新能学到有限伙伴策略。强预设方向的优势仍然很大，但“只有预设方向才能产生任何有用学习”不符合本轮数据。** 四个开发种子尚不足以确定这种改善的稳定范围。

## 核验和边界

128 条新生命全部独立重放了抽样动作、伙伴回应、身体结算和更新，9,441 次主轨迹与 22,848 次接收者回放更新通过。独立检查没有调用原 actor 更新、life/replay 或汇总函数：采用独立标量公式；动作概率与参数检查点最大差异为 0，汇总探针的浮点差异最大约 1.36e-7。Reference-RUL 的数值表和冻结表示仍共用归档实现，不能称为原论文全部数值方法的独立复现。

核心 CPU 恢复与新矩阵用时约 **21.68 秒**；速度来自已有冻结前缀缓存，不代表完整 Qwen 在线推理这么快。没有执行新的 4B/9B GPU 前向，没有训练 Qwen 主干，没有修改原失败实验。以前的批量缓存/单条前向数值差异仍然是完整部署验证的边界。
