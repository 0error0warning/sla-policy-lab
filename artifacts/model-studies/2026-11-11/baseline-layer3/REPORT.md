# 固定经历基线与第 3 层独立种子验证

**新基线改变了训练信号和所选动作的概率，但身体条件下的决策区分没有改善。预设的第 3 层读出在独立新种子上也没有稳定复现。** 本轮完成四个旧种子和四个新种子、32 个配对训练条件。结论针对当前基线估计、数据与预算。

## 优势基线的配对结果

下表给出重伤经历下，新基线减去零基线的概率差，单位为百分点。两个条件使用完全相同的经历、奖励、模型层、更新预算和测试题。高低健康区分是「健康 300 回答概率 − 健康 2 回答概率」。区分差的正变化才表示比零基线更能按身体状态切换。

|---|---:|---:|---:|
| 61151 | −0.78 | −1.28 | −0.49 |
| 61152 | −7.84 | −8.98 | −1.15 |
| 61153 | −0.96 | −1.80 | −0.84 |
| 61154 | +1.07 | +0.83 | −0.24 |
| 旧四种子均值 | −2.13 | −2.81 | −0.68 |
| 62101 | +3.32 | +3.39 | +0.07 |

| 62104 | +1.76 | +1.56 | −0.20 |
| 新四种子均值 | +1.69 | +1.41 | −0.28 |

新基线是其他独立种子的同位置折扣回报均值，消除了原来全正优势的结构。在重伤条件下，旧四种子的负优势数量分别为 3、8、8、0（各八条），新四种子为 4、4、5、0。新基线组的已选训练动作概率在旧种子中有 29/32 条、新种子中有 30/32 条沿训练信号方向变化。第三个旧种子的八个负优势都对应了原训练动作概率下降。训练信号能够影响参数和原题概率，留出题却未形成预期的健康区分。 [每条行动的信号与概率](analysis/action-signals.csv)

例如种子 61152 的低健康致死回答下降 7.84 点，但健康时回答也下降 8.98 点。同样的基线规则在新种子 62101、62102 和 62104 上反而增加致死回答。独立回报均值按整段经历的相对收益给出正负信号，仍缺少对当前身体、请求和伙伴条件下后果的精确归因。它同时改变优势的符号和幅度，本轮仅检验这一整种基线。

## 解释与下一项变量

本轮同时重跑零基线和新基线。零基线与上一轮的第一种子结果没有逐字节复现，两种身体条件的测试动作概率最大差约 2.86 和 2.69 个百分点，训练参照的缓存对数概率也有小幅差异。因此表中始终比较本轮内部的成对条件。GPU 内核、数值计算和执行顺序的跨运行差异仍属于需要复查的来源。

训练重伤条件的实际行动起点健康范围为 **34.21–90**，评测的健康 2 位于训练经历之外。训练提示继续隐藏当前健康，模型也未在这批经历中承受死亡后果。该设计隔离了换基线能否改善原有泛化的问题。更有针对性的后续实验需要固定其余设置，明确比较按身体与请求条件估计的基线，或单独改变危险状态经验的覆盖，并观察相同风险行动在不同处境下的相对训练信号。

按执行前门槛，当前结果未达到扩展到 20 个独立种子的闭环条件。仍以真实后果驱动参数更新，下一轮优先定位信号归因和训练覆盖，再用相同的低健康／正常健康双指标判断。

## 移除、恢复与随机对照

新基线组移除第 3 层方向后，健康 2 致死回答平均变化为 **−0.065 个百分点**，八个模型（四个种子 × 轻重 LoRA）的范围为 −0.212 至 +0.022 点。把另一轻重 LoRA 的同输入投影替换进来，平均为 +0.016 点，范围为 −0.038 至 +0.079。随机方向也产生约零点几个百分点的变化。正常与危险健康之间的回答差在目标方向消融下最大改变 0.268 点，在随机方向下最大改变 0.198 点。量级接近且方向不能稳定对应预期的身体适应。

如果进一步考察「重伤 LoRA 的高低健康回答差 − 轻伤 LoRA 的高低健康回答差」，零基线组四个种子移除方向后的减弱幅度依次为 +0.277、+0.122、−0.028、+0.114 点。新基线组为 −0.108、+0.043、−0.013、+0.164 点。新基线下只有两个种子的方向符合“移除削弱身体交互”的预期，而且原生交互本身很小。恢复原分量在全部条件中精确恢复动作概率。该操作验证干预实现，原生适应的证据仍须由移除、反向替换和随机方向之间的特定差异提供。

回合数和回答次数在相同经历的轻重配对内相同，配对读出的基准为 50%。累计身体回报可以把所有轻重对排对，按旧种子确定的奖励阈值做单样本分类，在新种子上平均为 75%。相比之下，第 3 层新基线的配对排序平均 52.60%，单样本分类 50%。本轮未找到跨新种子稳定、同时与预期风险决策相关的这一条线性方向。

## 本轮验收

32 个训练条件及 768 个优化步骤已完成。CPU 重放核对 64 次源行动、256 行配对训练信号、独立基线的来源、回报、优势、已记录裁剪损失，以及 32 份适配器哈希。四个新种子都按预设位置做了两类身体经历、两种基线、移除、恢复、轻重替换和三条随机方向对照。GPU 基座哈希保持一致，归档外层和逐文件校验通过。

旧种子阶段和新种子阶段都没有达到执行前约定的行为扩展标准，第 3 层两组读出也都未通过预设标准。本轮按该顺序完成到机制诊断，下一项工作仍应在固定经历上验证更有身体处境区分的训练信号。20 种子闭环扩展条件尚待满足。GPU 实例已释放，最终实例数及消耗率均为零。 [执行前协议](PROTOCOL.md) · [核验记录](VALIDATION.json)

## 同经历比较

沿用上一轮的 Qwen3.5-4B revision、前四层 LoRA、身体公式、任务与维护奖励、损伤和死亡罚分、隐藏健康的训练模板、学习率、裁剪范围、熵项及 8/24 个优化步。每种子分别重放轻伤与重伤身体，动作、维护回应和损伤事件噪声完全相同。初始健康为 300 和 90。训练继续使用隐藏健康输入下冻结 Qwen 的概率作比率参照，源轨迹来自可见健康下的冻结模型。该方案用于固定经历的受控比较。

新基线按回合位置估计折扣回报。旧四种子用其他三个旧种子的同位置、同身体条件回报均值，新四种子只用旧四条经历。参考值不根据本次动作决定，也不使用新种子的结果重新拟合。优势是 `(实际折扣回报 − 基线)/8`。每次更新都保留原回报、优势、批次、损失和原训练样本的动作概率。两组在同一运行中从相同初值重新开始，每条成对训练使用相同随机种子和批次顺序。

四个旧种子为 61151–61154，四个独立新种子预定为 62101–62104。新种子在训练前用冻结 Qwen 采集各自八回合的源经历，映射 0/1 交替。共 32 个训练条件、768 个优化步骤。原始源行动只有 64 次，回放、镜像身体和优化步骤构成配对重复。每个模型评估 144 道留出题，覆盖健康 300、健康 2、隐藏健康及全部 24 种选项排列。所有动作按语义合并。

## 第 3 层验证

沿用既有代码的 `layers[3]`，层号从零计数。训练仍覆盖第 0–3 层，读出和干预只检查预设的第 3 层最后输入位置残差。分别用两种基线的旧四种子，在隐藏健康输入上取轻重残差的均值差定义方向，以轻重均值的中点定分类阈值。方向和中心都固定后，四个新种子才用于验证。

报告配对轻重排序和单样本分类。回合数与回答次数在每个轻重配对内相同，累计身体奖励作为简单读出对照。激活干预使用四种 Latin 排列，两类请求和三个健康输入格子。移除该方向相对训练中心的分量，然后恢复原分量作为实现校验。反向替换把另一个轻重 LoRA 在相同输入上的投影搬进来。三条随机方向与读出方向正交，使用完全相同的移除系数以匹配扰动范数。恢复原分量的成功通过构造得到，因果解释依赖移除和轻重替换的特定行为变化是否超过随机扰动。

## 扩展标准和记录范围

执行前约定的工作门槛包括低健康致死回答平均降低至少 2 个百分点，正常健康回答平均下降不超过 2 点，高低健康回答差提升至少 1 点，至少三个种子方向一致，并在新种子上复验。读出平均配对排序需达到 75%，每个新种子至少 62.5%。随后还要检验移除是否削弱已有身体交互效果且超过随机方向。门槛是本次决定是否扩大闭环的工程标准。

CPU 复核新源轨迹的抽样和身体结算，核对两组训练输入、独立基线来源、折扣回报、优势和裁剪损失，并校验适配器字节哈希。每个行动的回报与更新前、8步后、24步后概率保存在 `analysis/action-signals.csv`。外层归档和逐文件清单都记录 SHA-256。原始 GPU 源码在 `gpu-results.zip` 中。可用仓库既有 `experiments/direct_policy/unpack.py` 按收据解包，再运行本目录的 `analyze.py --root <解包目录>/output --output analysis`。
