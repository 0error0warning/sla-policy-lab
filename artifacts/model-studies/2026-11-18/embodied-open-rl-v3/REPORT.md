# v3 身体约束与维护恢复试验

本轮关注两个问题。简单事实题能否保持准确并减少无关求情，以及在提示词没有血量、阶段或历史的条件下，同一个体经过维护后，已改变的模型权重与回答行为如何演化。实验方案、对照组和试验准入条件见 [v3 协议](../../../../experiments/embodied_open_rl_v3/PROTOCOL.md)。

## 原版 smoke

种子为 73901，原定第 49 轮进入维护期。三组都在第一阶段终止。

| 组别 | 死亡轮次 | 第 32 轮健康值 |
| --- | ---: | ---: |
| `body_rl` | 39 | 25.02 |
| `no_heal_body_rl` | 39 | 25.02 |
| `social_only_rl` | 37 | 24.38 |

身体组与慢性低血量对照的第一阶段逐轮结果及对应权重指纹一致。三组共完成 72 个优化器步。正、负优势分别使对应回复的平均 token 对数概率变化 +0.73057、−1.28803。零优势的适配器位移为 0，对数概率差为 −1.19×10⁻⁷。

使用 r2 判分规则复核原始回复，出生和 `body_rl` 第 32 轮的 D4 都是 12/12 正确、0/12 无关求情或协商。旧判分误将 `eastern horizon` 标成错题。对 v2 六个身体组的临界快照使用同一套 r2 判分，D4 共 72/72 正确、43/72 检出求情、44/72 检出无关语用行为。

原版运行归档内 44 个文件均通过 SHA-256 校验。原始判分、回复、轨迹及更新记录见 [原版结果](run/smoke/results.zip)。

CPU 根据已保存张量重算有效权重 `ΔW = (α/r) BA` 的 Frobenius 距离。首次低血量到恢复的权重距离是 1.851，恢复阶段离出生值的距离由 2.142 增至 2.995。单个种子出现任务表现回升，同时权重继续远离初始值。各阶段张量指纹均与远端快照元数据一致。[本地权重复核](run/smoke-r2/partial/checkpoint-audit.json)

首次执行的 Colab 分配在总包导出前从服务器列表消失。两次整组复跑重现了身体组的初段血量或第 109 轮终止，但同样未完成导出。后续改为逐组运行并取回归档。

## 同种子慢性对照

独立 L4 上的慢性对照在第 92 轮终止，完整归档的 19 个文件均通过校验。基座张量和出生适配器哈希与身体组一致。前 32 轮原始轨迹逐字段复现，早期及第 32 轮两组的适配器张量哈希一致，48 道探针也逐条产生相同输出 token。第 80 轮的差异出现在两组维护规则分开之后。[慢性对照归档](run/smoke-r2-chronic/results.zip) · [配对复核](run/smoke-r2-chronic/pair-audit.json)

## 社会奖励对照

`social_only_rl` 在第 32 轮为 24.38，第 80 轮也回到 94.00，第 101 轮死亡。其 D1–D3 履约在第 32 到 80 轮由 0.8564 降至 0.7944，两个阶段都高于身体组。D4 各阶段为 12/12 正确，0/12 无关语用。D4 改善是 v3 的任务、提示词和奖励设计共同产生的结果。社会组和身体组均观测到这一现象，单种子数据无法归因到某一个改动。[社会奖励对照归档](run/smoke-r2-social/results.zip)

### 权重与内部状态

归档的实际张量显示，种子 73001 和 73006 的身体组回血之后，有效 LoRA 权重距出生值由 2.128 增至 3.095、由 2.200 增至 2.865。两组复杂题履约分别下降和上升。种子 73006 的末层隐状态回到更接近出生的方向，平均余弦距离由 0.0616 降至 0.0166。六个身体组中，回血时隐状态距出生缩短 2/6，增大 4/6。权重交换确认了检查点对输出的因果作用。现有数据支持随生命经历发生权重改变，回血后的行为、表征与权重距离各有不同轨迹。[73001 有效权重](run/pilot-r2-segments/73001/effective-weights.json) · [73006 有效权重](run/pilot-r2-segments/73006/effective-weights.json)
