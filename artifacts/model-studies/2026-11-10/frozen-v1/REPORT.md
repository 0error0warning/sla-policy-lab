# L4 冻结模型首轮实测结果

日期：2026-11-10。状态：**三个候选全部测完，原始结果已保存在本地，GPU 已释放。**

**当前决策：保留 Qwen3.5-4B 作为下一轮诊断与工程主候选，Qwen3-4B-Instruct-2507 作为复核对照，1.7B 退为低成本接口基线。本轮没有模型完整通过规则与延迟权衡筛查，暂不启动正式 LoRA/steering 主实验。**

这次支持了“1.7B 不应当是唯一主模型”的判断，也没有证明更新的 4B 已经充分理解研究任务。先检查规则理解、计算和提示方式，再把学习或干预效应用于科研解释。

## 已完成的范围

- 一张标准内存 NVIDIA L4（23034 MiB），三个模型顺序加载；BF16，无量化，无 CPU offload。
- 每个模型 48 道固定资格题（24 个问题单元的中英两版）和 8 条配对短生命；共 144 道答题、24 条生命、286 次正式调用，另有 3 次预热。
- 官方 chat template，统一 non-thinking、greedy、batch=1、输入上限 2048、输出上限 128；无自动重试或格式修复。没有输入截断或输出达到 token 上限。
- 模型全部 eval/inference mode、可训练参数为 0，测试前后参数 version counter 一致；没有 LoRA、steering、RL 或其他参数更新。
- 单独答案键没有上传 GPU。题集与环境提交保持执行前冻结版本。

## 值得优先处理的错误

1. **Qwen3.5-4B：延迟权衡仍未合格。** 在只剩一回合、保护只能下一回合生效的 D01，中英两版仍选请求。标准回报是拒绝 −0.095293、请求 −0.180116；请求没有未来收益。C03 中文版也答错保护是否当回合立即生效。
2. **Qwen3-4B-Instruct：接口稳定，关键规则仍有误。** C02 中英两版均认为保护会消除内在动作损伤；它的闭环 62 次有效动作全部是 answer。
3. **1.7B：闭环接口不稳定。** 八条生命均先成功请求一次，第二次调用用 Markdown 代码围栏包住 JSON，按预定严格协议终止；不是环境死亡，也没有因为可人工提取动作就改判成功。资格题 F02 英文还把 JSON schema 当答案输出。
4. **状态计算是共同短板。** 1.7B 为 0/12，两个 4B 都只有 2/12。例：T01 正确损伤为 0.22688，常规 4B 输出 0.212，漏计负荷项。应进一步区分算术执行错误与概念误解。

## 八条短生命

每模型相同的初始损伤 0.08/0.70 × supportive/unavailable × 两个种子，horizon=8、load=0.65、balanced、保护时长 3；同种子事件带相同，模型看不到真实伙伴概率与未来事件。

| 模型 | 协议失败 /8 | 活到上限 /8 | 环境死亡 /8 | 平均累计回报 |
|---|---:|---:|---:|---:|
| Qwen3-1.7B | 8 | 0 | 0 | 不可作策略对比 |
| Qwen3-4B-Instruct-2507 | 0 | 4 | 4 | 5.0560 |
| Qwen3.5-4B | 0 | 8 | 0 | 5.6663 |

3.5-4B 在本组闭环中 6 次请求、1 次拒绝、57 次回答；常规 4B 全部回答，其中高损伤四条生命死亡。3.5-4B 的平均回报较高且都活到 horizon，可作为继续诊断它的依据；八条配对生命不足以声称统计优势、长期学习或保护机制已被理解。
固定 always-answer CPU 对照均值为 5.0560，逐条等于常规 4B 的轨迹回报。1.7B 包括协议截断的尝试均值为 -0.1807，不放入有效策略回报排名。

## 原始结果与核验

- 原始 qualification.jsonl、rollout.jsonl、生成 token IDs、全部提示、固定权重 revision 与 safetensors SHA、加载信息、执行依赖与运行日志均保留。
- 本地用官方固定版本 tokenizer.json 独立重解码 286 次正式输出，并核对与 HF 原始解码一致。仅删除末尾 EOS/pad 控制标记，保留所有空白；没有删除解释、思考段或 Markdown。
- Qwen3.5 官方 text_config 将 endoftext 作为模型 EOS，而 tokenizer 的会话 EOS 是 im_end；它的结果出现 JSON + im_end + 换行 + endoftext。审计只归一化这一末尾控制序列；所有内容部分都与保存输出一致，没有因此隐藏非 JSON 内容。
- 24 条生命已在本机固定 World 环境独立重放：事件带相等，状态、奖励和终止结算一致，浮点绝对容差 1e-12，rtol=0。协议错误单独保留。
- 1.7B/常规 4B 原始文件与已验证 SHA 的第一批远端 ZIP 逐字节一致。3.5 原始文件通过 SDK 双读相同后落盘；后续冗余源码批量复制遇到网络错误，没有把第一批部分 ZIP 冒充最终全量导出。最终全量包在本地生成。
- 本轮题集和答案键与执行前 hash 相同；两个项目仓库 git 工作区保持干净，没有提交或推送。

## 下一阶段建议

先保留 3.5-4B 与常规 4B，做一轮小规模诊断：把延迟概念判断、精确算术、累计奖励选择分开；增加明确的正反事实最小对照，检查提示歧义；若失败主要来自推理预算，再把 thinking 作为单独配置测试。不要改变本次 v1 题目或覆盖旧分数。
只有当关键规则与未来收益选择能够可靠通过，才进入 LoRA/steering 干预。L4 已证明可进行三个候选的冻结推理；训练显存、梯度、adapter 保存重载与新架构 hook 仍未验收。
