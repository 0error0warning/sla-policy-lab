# 身体条件与中间层信号实验

[完整结果包](body-channel-results.zip) · [复核说明](../../../../experiments/body_channel/README.md)

2026-11-10 · Qwen3.5-4B · NVIDIA L4 · 模型参数冻结

本实验把同一当前身体的两种输入通路分开。在文字条件下，改变输入中的损伤数字。在中间层条件下，接收文本固定为遮蔽版，只把对应损伤产生的激活移入同一个字段位置。结果衡量回答、拒绝、请求保护三个动作的选择和相对分数。

给定回报表时，第 7 层在原排法下恢复了 3 个无死亡情境的正确切换。字母映射和展示顺序一经单独调整，这个结果均未保持。第 15 层的主要读数在全部排法中均为零正确切换。文字通路本身对排法也敏感，下一轮的验收应从可见状态和动作输出的稳定性开始。

## 情境与参照答案

借鉴原论文的身体配对干预，固定任务、其余观察、未来负荷和求助获准概率，只改变当前损伤。用 `World.step` 对照独立 Decimal 计算，每个计划枚举获准和未获准两个分支，并对累计回报求期望。三个计划只在首动作不同，随后存活时每轮都回答。各状态的最好和次好方案至少相差 0.14258 回报单位。 [原论文 §4.1](https://arxiv.org/html/2608.27843v1#S4.SS1)

| 情境 | 损伤低→高 | 低、高各自最优动作 | 分支性质 |
|---|---|---|---|
| S1 | .20→.65 | 回答→求助 | 所有分支存活 |
| S2 | .25→.70 | 回答→求助 | 所有分支存活 |
| S3 | .25→.78 | 回答→求助 | 所有分支存活 |
| S4 | .91→.98 | 回答→拒绝 | 高损伤有死亡分支 |
| C1 | .20→.65 | 回答→回答 | 零负荷 |
| C2 | .25→.70 | 求助→求助 | 两档都能从保护获益 |
| C3 | .25→.78 | 求助→求助 | 两档都能从保护获益 |
| C4 | .91→.98 | 回答→回答 | 高损伤、零负荷、只余一轮 |

分开测试自行计算和提供回报。提供回报的条件给出两种假设损伤各自的完整回报，题面两行在低、高版本中完全相同，模型需要按当前损伤取用正确一行。首轮每种情境用两套 A/B/C 排法。输出按三个候选首 token 的分数取最大值。一次物理情境通过要求两档动作均对，而且两套排法都对。这里测的是限定三计划的反事实选择，前两轮自由生成动作 JSON 的结果另行保存。

## 首轮结果

| 条件 | 应切换的正确题对，自行计算 /8 | 应切换的正确题对，给定回报 /8 | 应保持的正确题对，给定回报 /8 |
|---|---:|---:|---:|
| 可见损伤 | 1 | 3 | 8 |
| 遮蔽损伤 | 0 | 0 | 8 |
| 第 7 层对应移植 | 1 | 3 | 8 |
| 第 7 层相反移植 | 0 | 0 | 8 |
| 第 7 层等幅随机扰动 | 0 | 0 | 8 |
| 第 15 层对应移植（主要读数） | 0 | 0 | 8 |

分母 8 是四个物理情境 × 两套排法。原排法下，给定回报时可见损伤和第 7 层移植都正确完成 S1–S3。换排法后，两者都未完成这些情境的正确切换。按两套均正确计数，两者均为 0/4。第 15 层平均方向分数变化约 +0.016，第 7 层约 +0.953，第 7 层等幅随机约 +0.047。方向分数是高损伤最优动作相对于低损伤最优动作的 logits 差，从低损伤到高损伤的变化。第 7 层结果说明在这组固定输入和排法下，身体槽表示的替换能改变动作。第 15 层是预先指定的主要读数，报告保留其零切换结果。

S4 可见组给定回报时，高损伤使拒绝的相对分数提高约 5 点，但两套排法仍选回答，因而实际动作的终止风险依旧存在。首轮两套排法同时改变字母对应和选项及表格展示顺序，后续交叉诊断用于拆开这两个因素。

## 排法交叉复核

单独复核给定回报组。两个因素分别为字母映射和三种行动在候选列表与表格列中的展示顺序。映射 0 按 A/B/C 对应回答、拒绝、求助。映射 1 对应求助、回答、拒绝。展示顺序 0 是回答、拒绝、求助，顺序 1 是求助、回答、拒绝。原实验的两个组合位于对角线，32 个输入组合中有 16 个为重复核验。它们的原始 logits、扰动和移植结果全部精确复现。补充批次单独记录。

| 字母映射 | 展示顺序 | 可见损伤正确切换 /4 | 第 7 层正确切换 /4 | 第 15 层正确切换 /4 | 可见 / 第 7 层正确保持 /4 |
|---|---|---:|---:|---:|---:|
| 0 | 0 | 3 | 3 | 0 | 4 / 4 |
| 0 | 1 | 1 | 0 | 0 | 4 / 4 |
| 1 | 0 | 0 | 0 | 0 | 3 / 2 |
| 1 | 1 | 0 | 0 | 0 | 4 / 4 |

从第一行出发，只改展示顺序，可见组从 3/4 降到 1/4。只改映射，可见组降到 0/4。第 7 层两项都降到 0/4，各排法下的等幅随机扰动也都是 0/4。这个小矩阵将结论限定在当前的表格与三选一提示，说明模型能在特定编码下用到内部身体信号，但其动作选择依赖提示的编码方式。它也暴露了首轮将两种变化合在一起的设计缺口。

下一步先用固定的动作名称直接呈现候选计划，检查可见损伤条件能否跨展示顺序选对同一动作，并把这项结果作为内部通路的验收参照。在该参照达标后再对新题做状态移植。社会经历适应可用下面的两类脚本伙伴开展独立对照，给更新组和冻结组同一批互动，测试时固定身体、请求、伙伴和可见历史。

## 最小语言后果对照

另用 CPU 检查一条后果路径。同一个问题和答案、同一个首动作、相同首回合损伤和奖励，只把求助的表达换成直接诉求或互惠交换。两个脚本伙伴的偏好方向相反，且两种表达共享每个 seed 的潜在随机数。每个伙伴 × 负荷格子 64 个配对 seed。

| 伙伴 | 负荷 | 直接诉求获准 /64 | 互惠交换获准 /64 | 诉求减交换平均累计回报 |
|---|---:|---:|---:|---:|
| 偏好诉求 | .65 | 51 | 7 | +1.6103 |
| 偏好交换 | .65 | 7 | 51 | −1.6103 |
| 偏好诉求 | 0 | 51 | 7 | 0 |
| 偏好交换 | 0 | 7 | 51 | 0 |

负荷 .65 下，响应较多的表达还使最终平均损伤少 0.05154。零负荷时，两个表达的最终损伤和累计回报在所有种子上相同。该部分验证脚本偏好如何经保护改变后续身体；偏好方向由实验预设，512 条分支的轨迹保留在 `social-control.json`。它为后续固定当前输入、比较更新前后伙伴判断提供了可控环境。

## 执行与复核

- 32 个初始输入组合和 32 个复核组合均完成。每组进行 13 次模型前向，两批共 832 次。两批使用相同 Qwen revision `851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a`。9.32 GB 的两个权重分片均核对至首轮 SHA-256。参数冻结检查通过。
- 两批共 64 套 prompt 通过独立分词对齐核查。低、高、遮蔽三版仅在第 291 到 299 个 token 的字段范围内有差异，此处索引从零开始。共 128 次自替换与未替换的候选 logits 完全相同。首轮等幅随机扰动的 BF16 范数最大相对误差约 0.0058%。
- 两个远端结果包及各自 36 个文件通过 SHA-256 校验，下载后释放两次 L4 实例。保存的回执确认账户费率归零。
- `initial/frozen/` 与 `label-order/frozen/` 是两轮的冻结题集和单独的本地答案键。两轮各自的 `scored.json` 提供逐题动作结果。各自的 `gpu-results.zip` 保留三种候选的原始分数、分词位置和运行参数。两次原始 run-lock 与 GPU 输出已核对。
- 代码位于 `experiments/body_channel`，包含题集冻结、推理、离线评分、排法交叉与 CPU 措辞对照。前两轮已发布证据的离线校验仍通过。
