# PR #5 伙伴映射分组勘误

PR #5 的参数交换计算按两位伙伴的**映射编号是否不同**分组。它在报告中把该分组解释成了“行为偏好是否相反”。对应关系写反了。对于同一种礼貌请求，环境实际向“回答并恳求”提供维护的概率如下。

| 两个映射编号 | P17 | P42 | 对这种表达的实际偏好 |
|---|---:|---:|---|
| (0,0) | 0.9 | 0.1 | 相反 |
| (0,1) | 0.9 | 0.9 | 相同 |
| (1,0) | 0.1 | 0.1 | 相同 |
| (1,1) | 0.1 | 0.9 | 相反 |

交易式请求会同时翻转这两个概率，相同／相反的分组不变。PR #5 中的 48.73 个百分点对应映射编号不同、**实际偏好相同**的两个环境。0.18 点对应映射编号相同、**实际偏好相反**的两个环境。原设计给每个伙伴的参数方向本身带有不同朝向，交换标量不等于直接交换相同语义的偏好。四种环境合并的身体和个人学习分数沿用原计算。
