# Diagnose finite-batch training coverage

The first true depth pilot showed that 32 eight-state updates at the terminal local MLP did not recover the large, full-grid policy. Independently of the remaining depth outcomes, diagnose this discrepancy in the measured final-block suffix on twelve new environment seeds 64811–64822, both mirror ecologies. No model or reward changes. Use the rank-four terminal LoRA, same initialization, native prefix states, RUL feedback, optimizer and gradient norm limit one. All methods draw from the same 49,152 observed actions per ecology.

Compare 32 eight-state original length-grouped minibatches; 32 batches balanced jointly across current health, partner and request frame; 32 updates using the exact pooled 256 state entries of the original schedule; 32 and 75 complete-grid updates; and 128 eight-state updates either reusing the same first 32 batches four times or using four independent schedules. The last two match update count and number of state evaluations while varying encounter coverage. The pooled 256 arm matches distinct observations and optimizer steps to the first arm but rereads them more times. Full-grid comparisons deliberately change the per-step information budget and are labelled accordingly. This numerical experiment isolates budget and gradient aggregation at the final block; the separate depth trial is the evidence for actual earlier-layer training.
