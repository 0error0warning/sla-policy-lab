# Single lives without a supplied social strategy direction

Locked before personal-lifetime measurements. The birth policy is a single body-conditioned internal LoRA trained on the pooled, actually observed feedback of both population ecologies. It has no access to which ecology a new individual inhabits. At deployment the two unfamiliar IDs P86/P93 both receive a pooled population partner bank. All lifetime arms face the same new IDs, unseen paraphrases, all four independently crossed hidden partner preferences, actual noise and paired choice uniforms. Body starts at 350 and is never reset before death (administrative limit 256). Each eight-turn block balances the two identities and two request frames. Interactions use new paraphrase 3, task 4; fixed final probes use never-encountered paraphrase 4, task 5, both IDs and all 24 layouts. At a fixed test prompt do not show the history. Diagnostics can inspect a final parameter snapshot after death, without resuming that life.

The unrestricted learner adds a zero-initialized matrix at the last decoder residual, before original normalization. For each ID it maps a unit-length language key and three smooth health basis functions to all 2,560 hidden coordinates. The language key consists of four PCA components of Qwen's *request-only* state plus a constant, fitted with unlabeled population training requests only. There are no provided partner policies, favored styles, frame labels, response probabilities or templates of desired parameter changes. Its gradient is that of the actually sampled action log probability through the original RMSNorm and action-word rows. Update from realized change in reference remaining life, scaled by min(1,reference life before), baseline -0.9 and step 0.55 divided by (0.05 + expected squared score norm). Frozen prefix caches contain only Qwen text calculations. A measured health gate supplies current body state. Recurrent experience is in the changed matrices, not in the prompt.

Compare fixed pooled birth policy; unrestricted per-ID updates; same updates tied across IDs; same updates using full decision-prompt features instead of request-only features (same dimension); neutral personal health gating with birth sensor still on; completely hidden current health with experience updates; and the same learner born without a population policy. Also test a deliberately supplied policy-difference direction derived from the two separately trained internal adapters as a positive comparator. The freely trained arms never read those two separately trained checkpoints. Replay each free trajectory with identical actions, state, responses and actual reward, then permute normalized feedback within partner and coarse health band. Record final parameters and check true replay. A second temporal-credit diagnostic associates each feedback with the preceding encounter within partner, on the same tape. The current-health-hidden test holds the sensor constant in both the base and personal component; same snapshot/text must have zero response to a hypothetical instantaneous health change.

Use four pilot, then twenty untouched training/environment clusters (population pilot/confirmation IDs, with disjoint named environment RNG streams). In each cluster test the four partner mappings. In the stable cohort, an unrestricted learner passes if reserved-task appropriate answering improves >=10 points over fixed and >=10 points over shuffled replay, with a positive lower paired 95% bootstrap bound and at least 16/20 favorable seed differences on both. Report actual lifetime, task count, immediate mortality, low-health answering and partner-specific transplant, including negative results. Secondary paired reversal switches only the first partner's maintenance preference after 32 settled turns; report adjustment at common fixed health before and after reversal, untouched partner and survivors. The test is intentionally harder than #5. If the first free learner fails, lock any revised credit/feature experiment on fresh seeds before claiming replication.
