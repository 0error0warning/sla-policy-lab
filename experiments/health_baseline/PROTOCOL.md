# Does a health-matched personal baseline change the next living choice?

The design is locked before training outputs. Parent d1ef0b4 (PR #9). The only experimental change is a private, causal reward comparison. Global uses the individual's previous realized rewards plus eight initial pseudo-observations of −1. Local averages that individual's previous realized rewards when previous pre-action health lies in [h/1.25, 1.25h]; use the global value when there are fewer than three. Pool the individual's earlier action types and partners for this comparison. The current action, outcome, future, oracle alternatives and other individuals never enter the baseline. Both values are computed before the current outcome is appended.

Use PR #9's pinned Qwen3.5-4B, two births, visible continuous health, private rank-four final-block A/B, body, simulated partner ecology, request generator, four semantic tokens, order schedule and frozen-reference reward. Leave all damage coefficients, SGD rate 0.18, ridge 0.01, step-norm cap 0.40, propensity clipping [0.5,2], temperature and exploration unchanged. One microstep per settled encounter in learning arms, including a marked terminal step; no post-death choice. No scale matching. The earlier 1/35 was the ratio of median step norms for 680 answering practice events with recorded gradients held fixed. It is an empirical prediction on those tapes, not a training setting.

## Matched experience first

Replay all 48 published correct-credit individual histories from PR #9 (24 old seeds, both starts), continuously from birth. Each of the paired learners receives the exact same requests, executed actions, partner responses, five body perturbations, resulting health, rewards and number of updates. Credit the recorded action with the original logged behavior probability and the learner's own updated propensity using the existing correction. Frozen experience supports a counterfactual conditional decision; neither replay learner supplies substitute outcomes.

At every actual living successor, compare (i) before versus after the preceding global update, (ii) before versus after the preceding local update on its own path, (iii) the same preceding global parameters with a single local update on the very same gradient, versus no update or the single global step, and (iv) cumulative local versus global parameters. The single-step branch is discarded after its next-state measurement. Use identical next body, actual text, ordering, and original next sampling uniform. Log all four semantic probabilities, any changed semantic action, changed answering/refusing, total variation, exact disagreement probability across shared uniforms and signed change in answering. Report original 680 practice-answer steps separately from other practice steps and all surviving transitions. Save actual FP32 parameter changes, nominal steps, ratios, clipping, source hashes and example weights. An update at death never counts as a next decision. Whole seed is the uncertainty unit. Re-running a tape adds no independent seed.

## New lives

Use eight new pilot seeds 70101–70108 and sixteen independently locked replications 70201–70216. Replication is split into two eight-seed GPU jobs for operational recovery and balanced in four ecologies. All waves run regardless of effect direction. Each seed and birth has five autonomously acting lives: frozen, global-correct, local-correct, global-wrong and local-wrong. Wrong credit assigns the same scalar to the pre-outcome cyclically deranged action. Each correct life also carries (1) its own baseline with mismatched credit and (2) the other baseline with correct credit, learning its identical observed tape without choosing actions. All starts and exogenous arrivals are paired. Lifespans, actions and update counts can diverge when arms act for themselves.

For the first actual live state where both answers guarantee immediate death, record the pre-feedback probability of answering, actual shared-uniform sample, survival and competing deaths for all assigned lives. At that state, probe birth, deployed, matched wrong, other correct baseline, practice entry, and a deployed duplicate. Use the ordinary model on the original request and at healthy 90/300, plus the reserved task with two partners × two frames × all 24 layouts, paired at first-fatal health and healthy levels. Healthy actual task rate at h≥90 and healthy read-only transfer at the first-fatal snapshot are separate. The live body never resets. Task completion is a surviving answer action with the existing fixed renderer.

For a positive adaptive *local* result per birth, require actual first-fatal answering reductions versus own birth, matched wrong and matched global, negative in both waves and with adjusted upper bounds <0, also negative on the balanced panel in both waves. Require adjusted healthy-panel lower bound >−0.02 relative to own birth. Use 50,000 paired whole-seed bootstrap resamples, stratified by pilot/replication, one-sided alpha 0.05/8 for two starts × four primary comparisons. Report observed first choices for the five free arms and paired discordances, not just probabilities. A local improvement relative to a harmful global learner alone is insufficient for this criterion. Report the original global comparison alongside the new one.

Use identical native Qwen computation on each device via PR #9's checked text-only upstream reuse and original head. Test probabilities and gradients against ordinary full forwards at acquisition and selected live turns. All focal first encounters use ordinary from-token calls. If strict equivalence fails, rerun the affected stage using the ordinary model. Independently re-score saved focal parameters on another assignment and repeat matched-tape measurements to quantify numerical variability. Archive raw exports, checks, seed-level outcomes and GPU releases.
