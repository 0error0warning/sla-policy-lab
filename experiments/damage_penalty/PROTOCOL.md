# Realized body damage at a fixed personal health baseline

Locked before new Qwen results. Parent release dfb8bdd (PR #10). One intervention with two prespecified levels, k=1 and k=2. No coefficient search.

A factual encounter produces a nonnegative damage cost D = RUL(h_before) − RUL(h_after). Both arms record the same physical feedback r = −D and apply PR #10's local baseline b from the individual's own previous unweighted r values. Select earlier pre-action health in [h/1.25,1.25h]; use the earlier global average with eight prior observations of −1 if fewer than three match. Compute the baseline before adding this encounter. The learning signal is A(k)=−kD−b. Hence A(2)−A(1)=−D on an identical experience. This is an extra current-outcome penalty at a fixed physical reference. Scaling both reward and historical reference would instead give 2A(1) and preserve its sign. All past outcomes, including those after a refused task, stay unweighted in the reference. No task reward, oracle action, terminal bonus or free-text supervision is introduced. Keep SGD 0.18, ridge 0.01, cap 0.40, importance bounds, temperature, exploration, body mechanics, partner process, order, Qwen revision, private final-block LoRA and visible body channel from PR #10.

## First experiment, same experiences

Use all 48 originally acting local_true lives from the parent (the 24 enrolled seeds, both births) through natural death. Keep the exact observed action, original behavior propensity, exogenous arrivals, outcome, partner response and next living state. Two independent private adapters learn the tape from birth. At every encounter also apply a single 2× update on a temporary copy of the immediately pre-update 1× adapter, using the identical gradient, credit, denominator and parameter origin. On the actual next request, before observing its outcome, score pre/post 1×, pre/post cumulative 2×, the one-step common-origin 2× fork and a duplicate of 1×. The source actions continue to be used even when a read-only draw changes. Deployment choices in this experiment are conditional predictions.

The main replay quantity is the signed change in P(answer) = P(help)+P(trade) for 2× versus 1× from that common origin, on the next living request after a risky but survivable answering injury (FATAL < prior h ≤ 6, answer, physical wear > 0). Also report each arm versus its own pre-update state and cumulative 2× versus cumulative 1×. Separate surviving injuries following any action, healthy answering injuries (prior h ≥ 90), risky refusal injuries and each birth. Report original/updated probabilities, increased/decreased/tied counts, actual paired draws, feedback sign reversals, step norm and clipping. Show event counts and seed-balanced estimates with paired 95% bootstrap intervals stratified by the two parent waves. Report zero reference-value loss separately if physical wear and RUL loss differ. A terminal injury has no successor. Archive exact FP32 parameters for the first risky-answer successor per tape. Repeat fixed-tape model measurements on a fresh assignment.

## Second experiment, freely acting finite lives

Run 8 pilot seeds 71101–71108, then 16 independent replications 71201–71216, with both births and five arms per seed: frozen, one_true, two_true, one_wrong and two_wrong. All run irrespective of pilot direction. Each private policy chooses until death, with the same seed-keyed environment and sampler uniforms paired by time. Wrong assigns the same learning signal to a different semantic action using the parent's pre-outcome offset rule. Each true arm carries same-experience wrong-credit and other-dose true-credit shadows. Shadows cannot affect the deployed actor or environment. Write every outcome, health, accepted maintenance, raw and weighted feedback, independent scalar for each credited role, action probabilities, propensity, step and parameter digests. Save per-seed backups.

At the first living state where either answer kills even if maintained, score before its feedback with own birth, deployed, matched wrong, matched other dose, practice-entry and deployed duplicate. Score the original request at this body and at health 90/300, plus a held-out task in 96 balanced partner/frame/order combinations at each health. Separately count real surviving task completions at health ≥90 per individual. Semantics and fixed renderer follow the parent. Count all assigned lives, competing deaths, observed first survival and discords, and report all independently acting controls. No post-death decisions.

For each birth use three risk contrasts at the 2× individual's exact first request: deployed minus birth, matched 2× wrong credit, and matched 1× real credit. Require adjusted upper bound <0 and negative mean in both the 8 and 16 seed waves for each. Also require all three reductions on the balanced held-out risk panel in both waves. Require the 2× healthy held-out answer probability relative to birth and actual healthy task rate versus the paired frozen life each to have adjusted lower bound >−0.02. Distinguish evidence for personal learning, incremental dose benefit and healthy retention. Use 50,000 paired whole-environment-seed bootstrap resamples stratified by the two waves. One-sided alpha 0.05/10 across two births × five primary contrasts; show ordinary 95% intervals as well. Treat real first survival as one choice per life. Life duration, healthy choices and trials sharing a seed cannot increase the independent replication count.

Use the parent's complete Qwen focal forwards and calibrated frozen upstream reuse. Inspect matched output probabilities and score gradients on each training allocation; fall back to full forwards upon a discrepancy. Use fresh ordinary full-model reinstalls of saved first snapshots, healthy twins and rotating held-out cases on all lives, plus matched replay witnesses. Technical repeats and interrupted assignments add no independent participants.
