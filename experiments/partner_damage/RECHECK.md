# 跨运行数值复查

首轮 34 项四格配对与干预全部完成。与 #19 比较，34 项事实更新的 FP32 哈希均不相同，预更新面板最大偏移为 17.47 个百分点。为限定原案例的定量解释，在读取第二块 GPU 的任何输出前登记一次独立技术复查。使用原预算余量、同一份固定基础权重、同一组八条已有生命中的数据，仅复查 77101 的第 33 和 37 次、以及第 1 次出生控制。原入口的第 3 行（从零计数）和本轮第 0 行均实际计分/求梯度，完整比较收到的相同输入、缓存面板与原生面板。在训练前运行，记录设备、软件、输入 ID 和权重哈希。两个主要个案按同样的四格、身份交换、向量交换与固定后续继续做一次，不选择哪个运行较接近预期才报告。本复查不扩样、不搜索内核配置、不改变位置和剂量。将根据原入口和本轮入口在同设备的差异、与档案及首跑的差异区分可以定位的数值问题和仍未知的来源。
