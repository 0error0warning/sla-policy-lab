# 最小计划接口与模型能力对照（v3）

2026-11-15，v2 完成后、v3 输出前锁定。v2 的行动增减量提取 14/14 正确，
但分计划预测仍错误，包括把另一计划的动作拿来计算。原联合门槛未过，原确认段未运行。

最后做一次固定、完整的小对照，不再无限细调提示：相同最小接口下比较固定
Qwen3.5-4B 与 Qwen3.5-9B（revision 沿用 #24/#25 的已核验版本）。
这检验两个具体模型配置，不把差异完全归结为参数数量，也不启动整套 9B 个体训练。

仍为四阶段、总输出上限 1,024、单题 60 秒：

1. 提取增减量：完全复用 v2 的提取提示和原非致死观测。
2. 预测 P：只给当前健康、P 的一个动作序列及模型自己提取的增减量。
3. 预测 Q：同上，只给 Q；不把 P 或历史中的其他序列放进该输入。
4. 选择：只给模型自己生成的两份预测与明示目标，由 Qwen 选择。

短的统一身体规则明确逐事件递推、A/B 都计任务、无健康上限、归零后不再执行。
这些公理与 v1/v2 相同；输入重排与简化作为**完整接口改变**评估，不声称只隔离
了一个字词的效果。程序选择要预测的序列，但不选最终行动，不计算未来数值，
也不校正模型的增减量、路径或任务数。选择仍可能受到错误预测影响。

两模型均固定运行原 28 个情境/信息条件（包括截至现在未见过模型输出的确认部分）。
这是新接口的完整比较，不是追认 v1/v2 通过原关口。保留开发/确认拆分，各自评分。
不根据开发分数选择性省略某模型的确认题；只因启动、资源或明确技术失败停止。
确认输出出现后不再修改此接口。总计最多 2×(2+28×4)=228 次生成，
总输出上限 61,440 token，推理最多 60 分钟，分配监督最多 75 分钟。
无 thinking、无采样、BF16、SDPA、batch=1、同类 L4。

原严格联合分数保持。另报告预先解释清楚的物理分数：所有实际执行到的健康值、
首次终止步和继续行动标志是否正确；不把终止后的 0/null 单独当成物理计算错误。
该补充分数不覆盖任务数与决策，也不替代严格门槛。终止后复活、计入未执行任务，
不能因忽略 0/null 表示差异而免于错误。所有模型生成、任务计数和最终选择均单列。

若最小接口可靠，后续可研究个人经历形成可用的身体预测；若仍不可靠，结论就是
当前模型/接口尚不能稳定承担这项后果链，停止用奖励或适配器更新来掩盖该缺口。
本段不训练权重，成功也不是私人参数学习或主动意识证据。
