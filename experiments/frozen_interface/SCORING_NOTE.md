# 动作容器歧义的补充核验（不替换主评分）

在取回 4B 第一条身体 direct 结果后、其第一条 thinking 尚未完成时，发现题面写的是“actions must contain wait, ask, help and trade”，没有明确要求 actions 必须是映射。该答案使用带 word 标签的四行数组，原始 CPU 数值 schema 只接受映射。因此不能将这种容器差异解释成不会算。

不改 GPU 提示、不重试、不改数字、不从推演正文提取值。保留全部主评分与事前门槛，并增加明确标注的事后结构核验：
- 原本的映射沿用原值。
- 数组仅在恰好四行、每行有且只有 word 或 action 之一作为身份字段、四个动作各出现一次，且其余字段精确为 after_action、after_no_maintenance、after_maintenance、p_death 时，重排成映射后调用同一数值评分。
- 不转换数值字符串、不补缺失、不处理重复动作、不修复 Markdown 围栏或数值。
- 原始解析对象、编码类型与补充结果一起保存。补充结果不覆盖主门槛；如果形式歧义影响关口解释，明确指出，不能据严格映射失败否定模型的计算能力。

这一核验只解决结构可读性，不保证内容正确。首次发现的数组本身也存在身体规则和风险错误，补充核验会照实记为计算错误，而不是将数组变成正确答案。
