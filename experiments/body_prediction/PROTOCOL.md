# 更换基座与身体后果预测：冻结对照

2026-11-15，在模型输出前锁定。用户授权继续使用 GPU，并提出更换 Qwen 与改变
学习目标。本段先分开两件事：更换模型的冻结能力；把任务从最终行动扩展到明确
的状态转移预测。本段不更新参数，不把预测题成绩称为个人学习成功。

## 模型与计算

- Microsoft `phi-4`，14B、MIT、普通密集 Transformer，版本与文件 SHA 固定在
  输入包。选它作为不同系列的可训练白盒对照，不声称是当前最新或最佳模型。
- Qwen3.5-4B 使用 #31 的同一固定版本，在同一个 A100 上重跑作配对。
- 两者均完整 BF16、SDPA、batch 1、贪心；使用各自原生聊天模板和结束 token。
  无 thinking、采样、量化、外部计算器、适配器或答案修正。
- 28 条原计划题：原 messages 不改，每条 1,024 输出 token/60 秒。
- 72 条新单步题：每条 128 输出 token/20 秒；每模型两条启动检查各 64 token。
  总计最多 204 次生成，输出最多 76,032 token；推理最多 60 分钟，分配监督最多
  90 分钟，包含安装、下载、校验与导出。正常/异常完成均释放本任务实例。

模型大小、系列、预训练同时不同，因此模型差异不能单独归因为规模或品牌。
旧 L4 结果保留；跨 GPU 原样重跑与本轮同台配对分别报告。

## 两组任务

1. 原 28 条整数身体完整计划题。沿用 #30 的输入、真值、目标和原联合门槛，
   记录完成、预测、选择、健康任务与不可逆终止。它们是归档探针，不宣称都是
   此次设计者从未看过输出的题；Phi-4 的本轮输出尚未产生。
2. 单步身体预测，3 个固定增减量世界 × 4 个查询健康值（0/1/3/8）× 3 动作 ×
   2 种信息条件 = 72 条。查询是反事实状态；用于推断固定规律的六条连续历史
   均来自健康状态、无终止。不得冒充查询状态与六条历史之间是一条实际完整生命。
   `rules` 给出增减量；`history` 只给非致死观察。公理包括固定加性代价、健康
   持续、归零后不能行动或恢复。只输出 `next_health` 与 `can_act_next`，不输出
   推荐动作、奖励或“保护自己”的台词。

零健康题检验吸收性，低健康题检验未亲历的终止外推，健康 8 检验正常继续。
单步题和多步题要求不同，不能把单步通过当成完整规划通过。按规则/历史、身体
世界和健康区间分别报告。重复条件不是独立生命，不能用 token 数当样本量。

## 事前决定标准

- 启动失败属于基础设施/输出通道问题，保存证据后修复；不计为身体能力失败。
- 新单步条件须 72/72 完整交付、至少 68/72 两字段全对，零健康 18/18、健康 8
  的 18/18 全对，才作为可继续训练验证的预测接口。
- 原完整规划仍使用原开发及确认联合门槛；单步分数不放宽规划门槛。
- Phi-4 若可靠优于同台 Qwen，成为下一次个人预测学习的候选；不能据此直接
  升级全部旧生命实验。若两者单步会、完整计划不会，下一项针对组合执行；若
  单步也失败，先查观测利用和状态转移，不用行动惩罚掩盖。
- 本段所有预定题都运行，不按开发成绩挑模型或省略题。技术预算失败如实保留，
  不把未交付记成算术错误，不增加 token 上限直至“成功”。

## 后续学习目标的接口（本段不训练）

可用于个人更新的数据单位应为本人真实发生的
`(h_t, action_t, partner_response_t, h_{t+1}, can_continue_{t+1})`，以预测实际后果
的误差为信号。当前“动作及标量反馈→动作概率更新”与此不同。死亡后的标签
不能算同一个体已用上的改进；未选行动和未来随机数不作为本人已经观察到的监督。

未来要保留相同出生参数、相同经历的冻结与反馈错配组，分别验证局部预测、
未见低健康与新动作序列、以及是否真正用于后续选择。预测正确不等于重视存活，
规则可见不等于经验在参数内，外部展开循环也不等于模型自发启动推演。
